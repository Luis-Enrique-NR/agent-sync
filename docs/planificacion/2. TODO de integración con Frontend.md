- **Estado:** En progreso

- **Rama:** `backend/ai`

## Objetivo

Completar la integración del AI Backend con Persistencia, Backend API, Transporte
y Frontend para ejecutar el flujo vertical del MVP:

```text
Configurar agente → iniciar negociación → mostrar conversación
→ solicitar aprobación → responder decisión → continuar o cerrar
```

## Definición de terminado

La integración se considera lista cuando una persona puede configurar su agente,
iniciar una negociación, observar la conversación, responder una decisión sensible
desde el Frontend, continuar después de una pausa, cerrar o retirar una sesión, y
recargar el estado desde la base de datos sin perder historial, autorizaciones ni
auditoría.
