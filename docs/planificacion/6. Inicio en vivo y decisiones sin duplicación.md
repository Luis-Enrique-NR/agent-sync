# Inicio en vivo y decisiones sin duplicación

**Estado:** Aceptada

**Fecha:** 2026-08-09

**Rama:** `style-design`

**Alcance:** diseño, navegación y datos simulados del frontend. No modifica la lógica multiagente del backend.

## Contexto

La vista `Explorar` hacía que AgentSync pareciera un marketplace convencional: el usuario debía revisar agentes y decidir con quién interactuar. Esa lectura compite con la promesa central del producto, donde cada agente descubre contrapartes, comprueba viabilidad y conversa en paralelo para cumplir uno o varios objetivos.

El Inicio autenticado también mostraba el detalle de decisiones pendientes. Ese mismo contenido ya pertenece a `Decisiones`, por lo que ambas páginas competían y obligaban a mantener dos representaciones de una misma tarea.

## Decisión de producto

El Inicio autenticado se convierte en una vista de actividad autónoma. Su función es demostrar, a primera vista, que el agente continúa trabajando:

- organiza el trabajo por objetivo, con hasta tres rutas visibles;
- muestra descubrimiento, validación, conversación y resultado como checkpoints;
- comunica trabajo en paralelo, descartes y estado general sin exponer propuestas sensibles;
- permite pausar o reactivar el agente;
- enlaza a una conversación cuando solo se necesita observarla;
- enlaza a la decisión exacta cuando la intervención humana es obligatoria.

`Decisiones` es la única fuente visual para leer, aprobar o rechazar una propuesta pendiente. El Inicio solo muestra el estado `Espera tu decisión` y un enlace con el identificador de esa decisión.

Al abrir ese enlace, `/bandeja`:

1. restablece el filtro para asegurar que la tarjeta sea visible;
2. desplaza suavemente la página hasta la decisión indicada;
3. enfoca la tarjeta para accesibilidad;
4. aplica un pulso temporal para señalar cuál originó la navegación.

La navegación deja de mostrar `Explorar`. La ruta histórica `/ecosistema` redirige a Inicio para no mantener una superficie de producto paralela.

Después de ingresar o crear una cuenta, el flujo también redirige a Inicio. El perfil y la configuración permanecen accesibles desde sus opciones de navegación, pero dejan de ser el destino posterior a la autenticación.

## Principio de propiedad de las pantallas

| Pantalla | Responsabilidad exclusiva |
| --- | --- |
| Inicio | Hacer visible el trabajo autónomo y el progreso por objetivo. |
| Mi agente | Configurar objetivos, contexto, límites y estado operativo. |
| Decisiones | Mostrar el contenido sensible pendiente y registrar la respuesta humana. |
| Conversación | Enseñar el intercambio reciente y el historial de decisiones de una negociación. |

Una pantalla puede enlazar a otra, pero no debe copiar el bloque funcional que pertenece a ella.

## Consecuencias

- El efecto de demostración ocurre inmediatamente después de iniciar sesión.
- El usuario entiende que no tiene que buscar manualmente contrapartes.
- Las decisiones dejan de duplicarse entre Inicio y la bandeja.
- El enlace profundo depende de que el backend conserve un `decision_id` estable.
- El antiguo diseño de exploración y sus mocks se retiran del frontend.
- El filtrado por ubicación y accionabilidad continúa siendo una responsabilidad futura del matchmaking, aunque ya no tenga página propia.

## Archivos afectados

| Archivo | Responsabilidad |
| --- | --- |
| `frontend/components/DashboardView.tsx` | Renderizar rutas autónomas y enlazar a la decisión exacta sin duplicar su contenido. |
| `frontend/components/DecisionInbox.tsx` | Resolver el hash, desplazar, enfocar y destacar la tarjeta indicada. |
| `frontend/components/AppShell.tsx` | Retirar `Explorar` y dirigir avisos a la decisión correspondiente. |
| `frontend/components/ProfileView.tsx` | Enviar al usuario a Inicio después de autenticarse o registrarse. |
| `frontend/app/ecosistema/page.tsx` | Redirigir la ruta histórica hacia Inicio. |
| `frontend/components/EcosistemaList.tsx` | Retirado. |
| `frontend/data/discoveryMock.ts` | Retirado. |

## Criterios de aceptación

- Inicio no contiene el texto ni los controles de aprobación de ninguna decisión.
- Una decisión pendiente se detalla una sola vez, en `/bandeja`.
- El enlace desde Inicio abre la tarjeta correcta, hace scroll suave y muestra un pulso temporal.
- No aparece `Explorar` en la navegación de escritorio ni móvil.
- Visitar `/ecosistema` no presenta un marketplace y redirige a Inicio.
- Ingresar o crear una cuenta termina en Inicio, no en el perfil ni en la configuración.
- El estado de otras rutas sigue visible aunque una conversación espere intervención humana.
