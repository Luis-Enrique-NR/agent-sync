# Próximos trabajos exclusivos de IA

- **Estado:** Propuesta
- **Fecha:** 2026-08-07
- **Rama:** `backend/ai`

## Contexto

El primer corte ya genera turnos estructurados, aplica guardrails y pausa decisiones sensibles. Las siguientes tareas pertenecen al comportamiento cognitivo y de seguridad del agente, no a Frontend, transporte, persistencia o matchmaking.

## Prioridad P0

1. Ejecutar smoke tests B2B y P2P con el LLM real y registrar latencia, coherencia y fallos.
2. Versionar prompts y ajustar instrucciones con conversaciones representativas.
3. Crear evaluaciones de negociación: convergencia, fidelidad a objetivos, consistencia de términos y calidad de descarte.
4. Agregar casos adversariales para precios ocultos, datos personales, referencias inventadas y prompt injection entre agentes.
5. Manejar refusals, respuesta vacía y salida estructurada incompleta con fallos seguros observables.
6. Convertir CRM, calendario, presupuesto e inventario mock en herramientas ejecutables con schemas y allowlist.

## Prioridad P1

1. Incorporar memoria acotada o resumen estructurado cuando el transcript crezca.
2. Ejecutar generación y grafo de forma asíncrona.
3. Registrar versión de prompt, modelo, tokens, latencia y códigos de política sin guardar secretos.
4. Comparar configuraciones de modelo sobre el mismo set de evaluaciones antes de seleccionar una para la demo.
5. Añadir un proveedor alternativo solamente cuando exista una necesidad real de fallback.

## Frontera con otros roles

- Persistir `NegotiationState`, controlar concurrencia y activar sesiones pertenece a Dominio/Persistencia/Orquestación.
- Publicar o recibir eventos de Portal pertenece a Transporte e Integración.
- Renderizar el core loop pertenece a Frontend UI.
- AI Backend entrega candidatos estructurados, resultados de políticas y eventos de dominio; no ejecuta esas responsabilidades externas.
