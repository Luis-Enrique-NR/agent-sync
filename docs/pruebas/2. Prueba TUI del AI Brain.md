# Prueba TUI del AI Brain

- **Estado:** Completada
- **Fecha:** 2026-08-07
- **Rama:** `backend/ai`

## Objetivo

Validar el motor de IA de forma aislada, sin depender de Frontend, Portal, matchmaking o persistencia. La herramienta es un arnés de desarrollo y no una pantalla del producto.

## Capacidades

- Selección de escenario B2B o P2P.
- Proveedor guionado sin credenciales o proveedor OpenAI real.
- Visualización de perfiles, turnos, términos numéricos y guardrails.
- Pausa visible cuando existe una decisión sensible.
- Aprobación, rechazo o reemplazo manual desde terminal.
- Modo `--auto-approve` para smoke tests reproducibles.

## Comandos

Demo determinística:

```powershell
cd backend
python -m ai.tui --scenario p2p --provider scripted
```

Demo con LLM real:

```powershell
cd backend
python -m ai.tui --scenario p2p --provider openai
```

La segunda variante requiere `OPENAI_API_KEY` configurada en `backend/.env` o en el entorno del servidor.

## Resultado verificado

El escenario P2P realizó oferta, contraoferta, detectó una solicitud de teléfono, pausó antes de publicar, aprobó el candidato y terminó en `RESOLVED` después de tres turnos.

La suite offline quedó en:

```text
30 passed in 0.18s
```

No se consumió la API real durante esta validación. La separación de referencias privadas se verificó con un cliente OpenAI falso que inspecciona el prompt construido antes de enviarlo.

El comportamiento detallado de los controles y de cada escenario está descrito en `docs/pruebas/3. Manual de controles y casos del TUI.md`.
