# Bus durable de transporte
- **Estado:** Completada
- **Fecha:** 2026-08-08
- **Rama:** `feat/durable-transport-bus`

## Contexto
La admisión de webhooks necesita conservar cada sobre aceptado para procesarlo al menos una vez, incluso después de reiniciar consumidores.

## Decisión
`RedisStreamsEventBus` mantiene la interfaz pequeña `accept`, `receive`, `ack` y `fail`. Lua valida previamente los tipos de las claves, deduplica por `event_id` y agrega el sobre de forma atómica. El grupo se crea de forma idempotente; `XAUTOCLAIM` recupera entregas vencidas y solo `ack` confirma éxito. `fail` registra metadatos limitados y no confirma la entrada.

## Consecuencias, riesgos y pendiente
Redis debe ejecutarse con persistencia y propiedad operativa antes de habilitar consumidores. La evidencia ejecutó Redis 7 con AOF, reinició el contenedor descartable y recuperó la entrada pendiente con otro consumidor. No se habilitó ninguna ruta ni se modificó `backend/ai`.
