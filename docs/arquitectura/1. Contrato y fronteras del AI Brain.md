# Contrato y fronteras del AI Brain

- **Estado:** Aceptada
- **Fecha:** 2026-08-07
- **Rama:** `backend/ai`

## Problema

Acoplar LangGraph a REST, almacenamiento o Portal impediría probar el motor de forma determinística y haría que los dominios del SRD se mezclaran.

## Decisión

El AI Brain se implementa como un módulo de dominio con tres operaciones públicas:

```text
start_session(...) -> EngineResult
run_until_pause(state) -> EngineResult
resume_session(state, human_decision) -> EngineResult
```

El resultado contiene el estado actualizado y eventos de dominio. El Backend API es responsable de persistirlos y de publicar los eventos autorizados en Portal.

El proveedor real implementa el puerto `LLMProvider`. El proveedor falso implementa el mismo contrato para pruebas. Ningún modelo, SDK o transporte se importa desde los modelos de dominio o las políticas.

## Consecuencias

- Las pruebas no requieren red ni credenciales.
- El proveedor puede reemplazarse sin modificar el grafo.
- Backend API debe persistir el estado retornado antes de invocar nuevamente el motor.
- La resolución de referencias privadas pertenece a una capa segura fuera del LLM.
